# Islandify ticket records

These records are the durable project context for long-running Codex goals. They are intentionally separate from application source files.

- `001-harness-and-timer.md` — repository harness baseline and environment constraints.
- `002-islandify-v1-goal.md` — the single-goal product contract for the first implementation.

For a goal run, update the active ticket’s progress and verification sections as work lands. Keep product decisions and non-goals here so a resumed goal does not depend on an earlier chat turn.
