# Islandify visual concepts

The five concept screens below use the supplied capsule-and-character artwork as the visual reference. They are exploration assets only; the current app icon uses the supplied image itself.

1. `Islandify-Concept-01-Glow-Capsule.png` — bright, airy home dashboard with the capsule as the primary timer.
2. `Islandify-Concept-02-Midnight-Neon.png` — high-contrast night mode with cyan/magenta neon edges.
3. `Islandify-Concept-03-Bubble-Desk.png` — translucent glass cards for the five activity areas.
4. `Islandify-Concept-04-Aurora-Ring.png` — circular progress ring built from the same gradient language.
5. `Islandify-Concept-05-Minimal-Island.png` — minimal editorial layout with a single dominant capsule.
